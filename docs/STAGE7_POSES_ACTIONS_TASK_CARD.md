# 任务卡：企鹅侧背面与基础动作

- 归属：阶段七角色展示；基于已合入的正面母版、表情与行为运行时。
- 输入：现有 CharacterView 的 pose、animation、expression、behaviorId 与 amplitude；输出：只读 SVG 角色表现及开发预览。
- 公共契约：无变更；不改变 BehaviorDecision、存档及调用方。视觉参数仅用于呈现，不改变行为配置版本。
- 依赖：PR #27、#28、#29；侧背面依据正面原创延展，视觉待用户验收。
- 不做：特殊动作及启用、正式小屋 UI、饰品、性格评分、AI、行为抽样或存档变更。
- 最小验收：四方向静态对照；呼吸眨眼、转身、行走、坐起、休息、挥翅、注视、轻跳可预览；低动态、隐藏暂停；角色页面与行为运行时回归；类型检查、lint、生产构建与浏览器预览。
- 存档与迁移：无变更；无持久化写入。
- 风险：侧背面与动作视觉待用户验收；动画参数为视觉待验收值。
- 第二轮视觉优化：区分安静休息与蜷缩，增强现有动作和靠窗沉思问号；仅调整展示层及预览，动作视觉待用户验收。
