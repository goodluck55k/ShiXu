# 阶段九：企鹅生命感与语言表达升级

> 状态：规划已获用户确认（2026-11-18），按 PR ① → ② → ③ 顺序推进。阶段九与阶段八相互独立：阶段八继续负责集成、部署与比赛交付，其必要交付不得被本阶段挤占或阻塞。

## 1. 目标与原则

本阶段只做三件事：

1. **生命感**：让企鹅在任何时刻都像"活着"，扩展动作、表情与自然动态。
2. **语言表达**：本地台词与气泡，为未来 AI 对话与语音预留接口。
3. **融合与反馈**：改善企鹅与现有小屋插画的融合，补足必要的交互反馈。

原则：

- 体验优先于技术复杂度与功能数量；能局部扩展就不重构。
- 四个页面（小屋、日记、回忆、许愿屋）、侧栏与状态卡布局保持基本不变；不重设计页面。
- 复用现有角色结构：`PenguinFront` 已有独立的翅膀/双脚分组，`PenguinFace` 有 `data-part="face"` 与 `data-eye`，动画沿用 CSS 关键帧 + `--amp` 幅度变量与 Web Animations API；不拆母版、不引入新动画框架或依赖。
- 所有新增表现属于展示层：不改性格算法、主导判定、行为调度规则与存档；不新增奖励、货币、等级、成长加成。
- 尊重 `prefers-reduced-motion`、页面隐藏暂停与现有可访问入口（三个互动按钮保留）。

## 2. PR ①：生命层与场景融合（`feature/stage9-life-layer`）

### 2.1 常驻生命层

在 `CharacterRenderer` 的动作层 `penguin-body` 外包一层 `penguin-life` 分组，两层变换自然叠加，动作关键帧保持原样：

- **眨眼**：所有动作期间都眨眼（现状只在 `breathe` 时眨眼）；两组不同周期关键帧叠加形成不规则节奏，偶有连眨。
- **呼吸**：极轻的常驻起伏，坐姿与站姿幅度不同；不与动作层的 `breathe` 叠加过量。
- **视线**：仅小屋场景，指针移动时脸部朝指针方向偏移数像素（节流、上限钳制），暂停/低动态时关闭；仅改展示，不触发任何行为。
- **偶尔歪头**：低频脸部微旋转。
- 低动态偏好：生命层整体关闭，保持静态正面形象。

### 2.2 动作衔接

- 走路朝向切换由硬切改为短交叉淡入；落地加轻微压缩回弹。
- 坐下/起身复用 `penguin-sit`，加下沉回弹。
- 为挥手、蹦跳、回应等现有关键帧补预备与余韵（缓动与关键帧调整，不改时长配置）。

### 2.3 场景融合（仅小屋场景）

- 将偏绿的平椭圆投影换为暖色柔和投影。
- 以场景作用域的叠加层为企鹅增加很淡的体积明暗与窗侧暖色边缘光；母版 SVG 与其他页面的企鹅不受影响。
- 尺寸只做小幅调整，先截图对比再定；不改小屋布局。

## 3. PR ②：本地台词与气泡 v1（`feature/stage9-speech-bubble`）

### 3.1 呈现

- 企鹅头顶手写风小气泡，跟随企鹅，逐字出现，数秒后淡出；状态卡保留不动，气泡是额外一层。
- 每句约 20 字以内；`aria-live="polite"` 朗读；低动态时直接整句显示。

### 3.2 触发时机

进入小屋问候（按时间段/久别）、三种互动回应、保存日记后的情绪回应、久别重逢与离线小事、特定行为自言自语（如靠窗沉思、观察物品）、低频碎碎念。

### 3.3 不机械的表达

- 台词库为带版本号配置 `speech-v1`（`src/config/`），按「时机 × 主导性格 × 时间段」组织，每组多条备选；选句为纯函数，使用显式种子并记住最近说过的若干句以避免重复；全局冷却，低频说话。
- 性格差异体现为**倾向**而非固定口癖：同一性格的台词在句式、长度、语气上有多样性，口吻特征只是出现概率较高，不在每句重复同一标记（用户 2026-11-18 要求）。
  - 温柔：轻、慢，常关注用户；好奇：常提问、注意到细节；开朗：轻快、偶有拟声；害怕：话少、迟疑；低落：短句、安静、可能只说半句。
- 台词底线：不说教、不灌鸡汤、不诊断、不评价用户情绪对错；记录悲伤时回应「陪伴」，不要求用户"开心起来"。「低落」仅为角色倾向，不指向用户心理状态。
- 台词不写入存档，不改变任何正式状态；不使用 AI。
- **台词初稿须先提交用户确认**，确认后再接入正式配置。

### 3.4 未来扩展接口（只预留，不实现 AI/语音）

- 统一台词数据结构 `{ text, tone, source: "local" | "ai" }`，通过「台词来源」函数获取；未来新增 AI 来源时保留本地来源作为回退。
- 气泡显示时提供「开始说话」回调钩子，未来挂接企鹅叫声或语音合成。

## 4. PR ③：动作扩展与互动反馈（`feature/stage9-actions-interaction`）

### 4.1 丰富现有行为表现（不改行为规则）

按 `behaviorId` 给原本只用 `breathe`/`none` 的行为增加专属表现：观察物品（前倾歪头、连眨）、东张西望（视线左右扫）、低头发呆（慢呼吸、低头、偶尔叹气）、犹豫靠近（走走停停）、轻轻后退（先缩后退）、温柔注视（慢眨眼）、独自坐着（晃脚）等。性格差异通过已有 `amplitude` 与节奏参数体现。

### 4.2 新增日常小动作：打哈欠、伸懒腰、梳理羽毛、打盹

- 优先方案（不新增行为 ID、不改 `behavior-v2` 规则）：作为现有环境待机行为 `idle_breathe` / `idle_glance` 的**展示变体**，由展示层根据当前决策的确定性信息（行为、开始时刻等）与时间段选择，例如清晨偏伸懒腰、深夜偏打哈欠与打盹；不使用 `Math.random` 影响任何正式状态。
- 若实现中确认必须新增行为 ID 或修改行为规则（例如需要独立权重或时长），则按规范升级规则版本、同步 `COMPANION_SPEC` 与 `ARCHITECTURE`，并在 PR 标注「参数待验收」。

### 4.3 直接互动与回应

- 点击企鹅头部附近等同「摸摸头」：压扁回弹、开心表情、小爱心与一句台词；悬停时光标变化、企鹅看向指针。三个按钮全部保留为可见、可键盘操作的入口；点击仍经现有 `interact` 入口，不新增持久效果或奖励。
- 「呼唤」：转身朝向屏幕后小步走回中央；「凑近看看」：前倾、眨眼。

## 5. 后续规划（保留，不在本阶段实现）

- **AI 自由对话**：用户主动与企鹅聊天，结合主导性格文字描述、当前情绪、近期事件与经授权的记忆；阿里云百炼生成，本地台词回退。超出 AGENTS §2.3 现行 AI 权限（仅识别情绪），实施前必须先修订 AGENTS 与 `AI_CONTRACT` 并经用户批准；模型输出只能是文本与有限语气，不得决定动作、修改性格或存档；需危机内容安全策略与成本保护。
- **企鹅语音**：先评估本地合成的"企鹅语"音节，再评估百炼语音合成；默认静音、用户开启，语音与表情、嘴部动作联动；挂接 PR ② 的「开始说话」钩子。
- **长期陪伴**：更丰富的自主生活与独特习惯；属于新机制，需单独设计与批准。
