# 回忆手账第一轮视觉对照（待用户验收）

截图来自本地生产构建和 Chrome 浏览器；记录通过隔离浏览器中的日记页面手动保存，仅用于验收，不是产品默认数据。手机长截图中的固定导航显示在截取时的视口位置，滚动时实际固定在屏幕底部。

| 对照项 | 当前实现与剩余差异 |
| --- | --- |
| 桌面比例 | 侧栏与中央双页结构已实现；1920 宽屏书页比概念图更宽，1440×900 需要向下滚动才能看到完整书底和翻页区。 |
| 木边、书脊、叠页 | CSS 多层边框、阴影和中缝形成厚度；纹理仍比概念图规则，木纹与弯曲书页不够自然。 |
| 纸张、撕边、阴影 | 暖纸底、横线和轻微边缘纹理已实现；真实撕纸纤维、纸面颗粒及不规则轮廓仍较简化。 |
| 胶带、便签、植物 | 错位便签、格纹/波点胶带、原创 SVG 植物和统计方格已实现；枝叶、花朵、纸夹、贴纸的丰富度与手绘细节低于概念图。 |
| 企鹅 | 复用已确认企鹅母版，配静态书本；与概念图中阅读企鹅、靠垫和茶杯的构图不同，角色不作新姿态或资产。 |
| 字体、间距、颜色 | 使用系统中文字体和暖棕、奶油、鼠尾草绿；字形、手写质感和纸张色彩仍与概念图不同，各平台字体会有差异。 |
| 手机 | 单页正文优先、统计、装饰、记录选择和固定三入口已实现；记录索引位于详情后，页面比概念图长。固定导航可随滚动覆盖非交互装饰，但底部操作可滚入可视区域。 |
| 翻页 | 仅呈现禁用控件并标明待接线；没有伪造页码或分页规则。 |

检查覆盖：1440×900、1920×1080、390×844 与手机全页；空态、记录选择、正文编辑、情绪纠正、刷新恢复及长正文末尾。截图视口未发现横向溢出；未做实体设备、非零安全区、跨浏览器及屏幕阅读器验收。
