# 拾绪 ShiXu · 产品规格 v3

> 状态：V1 方向基线。本文描述**产品要做什么**，不规定实现细节；数值参数集中在 [COMPANION_SPEC](COMPANION_SPEC.md) §2、§3，接口与存档结构见 [ARCHITECTURE](ARCHITECTURE.md)。标注「已实现」的内容以 `main` 分支代码为准，标注「候选」「待确认」的内容不得当作已批准规则。

## 1. 产品定位与当前状态

拾绪是一个情绪陪伴养成 Web 应用：用户每天写下真实的日记、确认自己的心情，一个原本全白、没有装饰的小人按确定性规则慢慢形成性格，并用表情、动作、自主行为和互动把这种长期变化表现出来。

V1 的三件事：

1. **情绪记录**：原文日记 + 九类情绪手动确认 + 可选 AI 建议。
2. **长期性格养成**：性格由长期确认过的情绪逐渐形成，不是当前心情的复制，也不是一次性数值奖励。
3. **自主行为与互动**：性格决定小白人偏爱做什么、怎么回应；当前情绪决定即时表情与反馈；用户能感到「这是我的小人，它和我相处久了」。

设计取向：长期陪伴、个体差异、养成感。不追求短期刺激、连续签到、等级战力或收集压力。

## 2. 核心循环

1. **写日记**：用户写下当天的正文。正文原样保存，不做 AI 改写、润色或生成，不设产品人为字数上限。
2. **确认心情**：用户从九类情绪中选择一类，并可调整 VAD 维度与强度；AI 建议只是可选辅助，必须由用户确认或修改后才进入保存。
3. **保存并成长**：保存成功后，性格引擎按确定性规则把这次「已确认情绪」计入长期性格台账；保存失败不产生任何正式成长。
4. **陪伴与行为**：小白人依据长期性格、当前情绪、显式互动和时间/种子上下文做出自主行为与即时反馈。
5. **回看**：用户在回忆页查看历史日记与情绪，在陪伴页观察性格描述与行为差异。

一次记录只发生一次成长结算；重复点击、刷新、重试不会重复计分；纠正情绪替换原贡献而不是叠加；编辑正文不改变性格贡献。

### 2.1 四种机制

| 机制 | 职责 | 不负责 |
| --- | --- | --- |
| 情绪确认 | 规范化九类情绪与 VAD；给出手选与 AI 建议两条路径 | 不直接改性格、不决定动作 |
| 性格养成 | 把长期确认情绪累积成五维倾向；提供描述与只读查询 | 不渲染界面、不直接选择动作 |
| 自主行为 | 依据性格偏好、当前情绪、互动与上下文选择有限行为 | 不改性格、不写存档、不调用 AI |
| 互动反馈 | 对呼唤/触碰等显式互动给出即时反应；保存后给一次性情绪反馈 | 不刷性格、不产生持久奖励 |

## 3. 情绪

- 九类情绪固定为：喜悦 `joy`、平静 `calm`、难过 `sadness`、焦虑 `anxiety`、生气 `anger`、疲惫 `tired`、复杂 `mixed`、一般 `neutral`、未知 `unknown`。
- 每条情绪记录包含 `valence`、`arousal`、`dominance`、`intensity`（0–1）、`confidence`（AI 为 0–1，手动/纠正为 `null`）与来源 `source`（`ai` / `manual` / `corrected`）。
- 手选情绪使用 [AI_CONTRACT](AI_CONTRACT.md) §4 的默认 VAD；用户可在保存前调整维度与强度。
- AI 识别是可选项：未配置 API Key 时必须能只用手选完成完整主流程；AI 失败、超时、格式错误、低置信度都必须回落到手选，且用户始终可以改判。
- 情绪标签是性格结算的主依据；VAD 与强度用于即时表情、行为偏好和幅度缩放，不额外制造第二套评分。置信度只用于提示用户复核，不参与计分。
- 用户纠正已保存记录的情绪时，以替换方式重算该条贡献；历史日记正文与已形成的性格结果不删除、不回退、不追溯惩罚。

## 4. 性格养成

性格是小白人的**隐藏行为倾向**，不是用户的健康指标、心理诊断或人格测评，也不直接展示精确分数。

- 候选维度（五维，名称与数量待用户确认）：活泼、勇敢、温柔、敏感、好奇。
- 初始状态为中性基线；具体初始分、上下限、单次与单日变化上限见 COMPANION_SPEC §2。
- 每类情绪对五个维度有方向不同的基础影响；强度参与幅度缩放；VAD 不重复计分，主要用于当下表现（见 COMPANION_SPEC §2.6）。
- 性格可以**双向缓慢变化**：长期偏向某一侧后，继续同方向变化会因惯性变小；单次记录不能造成剧变。
- 悲伤、焦虑、愤怒**不是人格缺陷**，也不触发任何惩罚、扣减资产或负面标签；它们同样会带来细腻、温柔或勇敢方向的成长。
- 用户只能看到自然语言描述（例如「最近更容易先照顾别人的感受」），不能查看精确分数、不能手动加点、不能选择培养路线。
- 规则以版本标识（`personality-v1`）固定在配置中；调整规则不追溯改写已保存记录。
- 「性格状态查询」是只读契约：行为模块、角色展示模块和未来的 V2 饰品模块都只能读取，不能写性格内部状态。

## 5. 自主行为与互动

- 行为由**确定性规则 + 有限行为集合**产生，不使用复杂行为树、通用游戏引擎或多模型编排。
- 行为上下文 = 只读性格快照 + 当前已确认情绪 + 显式互动事件 + 应用层显式提供的时间/种子。
- 性格决定行为**偏好**（例如好奇高更常探索，温柔高更常安静陪伴）；当前情绪决定**即时表情与反馈**；互动可以短暂打断自主行为。
- 同一时刻只有一个主要行为；每种行为保留最低出现机会；同一行为不连续超过两次（候选参数）。
- 页面隐藏时暂停行为调度；关闭网页不模拟离线生活，也不产生离线经历或离线成长。
- 用户互动不得直接增加性格分数或绕过保存流程；互动反馈是即时的、非持久的。
- 行为模块可以新增动作而不修改性格算法；角色展示层只负责按 `CharacterView` 渲染，不修改性格或存档。
- AI 不得决定动作、生成可执行行为指令，也不参与行为选择。

## 6. 页面责任

V1 保留三个路由，页面职责如下：

| 路由 | 页面 | 责任 |
| --- | --- | --- |
| `/` | 记录 | 写日记、选择或调整情绪、查看 AI 建议并确认、保存；处理保存失败、草稿、异常恢复提示 |
| `/companion` | 陪伴 | 展示小白人、当前表情/动作、自主行为、互动入口、五维性格的自然语言描述；保存成功后的一次性情绪反馈 |
| `/memories` | 回忆 | 按时间查看历史日记原文与当时确认的情绪；支持纠正情绪、编辑正文；展示必要的保存状态 |

页面只通过应用服务与公开契约读写状态，不直接访问其他模块的私有数据。

## 7. 数据与存档

- 正式状态以完整 `Snapshot` 为单位一次写入；只有存档成功后才确认成长结算。
- 存档带版本号、修订号与幂等事件记录；旧版本存档在读取时迁移，迁移不修改已有日记正文、情绪、纠正记录与历史。
- 损坏、不可识别或版本过新的存档保留原始数据，提供导出/重置路径，不静默覆盖。
- 不要求登录、云同步、数据库或后端账号体系；V1 使用浏览器本地存储，通过 `StoragePort` 隔离。
- 详细结构、迁移规则与失败处理见 [ARCHITECTURE](ARCHITECTURE.md) §4、§6。

## 8. 范围与非目标

V1 明确不做：

- 饰品、装扮、库存、解锁/隐藏/恢复/穿戴玩法与对应界面。
- 商城、交易、点数、货币或付费内容。
- 经验值、等级、成长阶段、每日签到、连续天数奖励等旧成长体系。
- 复杂 Agent、多模型编排、微服务、消息队列、向量库或通用插件系统。
- 社交、PK、多人、语音、3D、无限聊天或医学/心理诊断。
- V1 稳定前提前实现 V2 业务。

旧机制处理：

| 旧机制 | 处理 |
| --- | --- |
| 每篇日记 XP、阶段（0/30/80）、XP 解锁饰品、消极情绪隐藏饰品 | 废止，不再结算、不再展示；旧存档字段只做兼容保留 |
| 装饰三态、动态回收、穿戴槽位 | 后置到 V2；V1 不实现、不评估、不展示 |
| 长期习惯、世界成长痕迹、情绪种子 | 不属于 V1；旧存档数据保留但不参与 V1 规则 |
| 三内部维度（探索欲/静心度/亲近倾向） | 由五维性格体系替代；旧台账不追溯换算（待确认） |

## 9. V2 饰品扩展边界

V1 只为 V2 预留**契约级**扩展点，不实现任何饰品业务：

1. **只读性格查询**：V2 可按性格快照与成长事件判断装扮表现，但不能写性格内部状态。
2. **已确认领域事件读取/消费**：V2 可消费 `ENTRY_SAVED`、`EMOTION_CORRECTED` 等已落盘事件，自行维护饰品状态。
3. **角色外观扩展点**：`CharacterView` 预留可选外观配置（图层白名单），V2 通过注册外观提供者叠加饰品图层；角色展示层仍只渲染，不判定解锁。

V1 不实现饰品库存、装扮 UI、解锁算法、动态插件加载器或复杂事件总线；现有通用接口能满足时不新增重复接口。V2 必须作为独立模块和独立阶段接入，不大规模重构性格与行为核心。

## 10. 演示与验收

最小可演示线：

1. 新用户写一篇日记，手动选择心情并保存；刷新后正文、情绪与性格描述仍在。
2. 同一天重复点击保存不重复计分；编辑正文不改变性格；纠正情绪后描述按替换规则变化。
3. 连续多天记录不同情绪后，五维描述出现可解释的差异。
4. 陪伴页的小白人按性格与当前情绪做出不同行为/表情；互动有即时反应，且不增加性格分数。
5. 未配置 AI Key 时手选全流程可用；配置 Key 后 AI 建议必须经用户确认才生效。
6. 损坏存档、版本不兼容、存储不可用时有明确提示与恢复路径。

详细数值验收与阶段验收见 [ROADMAP](ROADMAP.md) 与 [COMPANION_SPEC](COMPANION_SPEC.md)。
