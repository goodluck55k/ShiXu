# 拾绪 ShiXu · 产品规格 v2

定位：**情绪陪伴 + 半自主虚拟伙伴 + 隐藏性格养成 + 可成长的生活世界**。核心理念：「你的情绪，正在塑造一个小世界。」用户记录自己的日常心情，小白人根据长期情绪经历逐渐形成性格倾向，拥有自主行为和生活习惯，并与用户一起留下回忆。产品不再以「写日记获得 XP」为唯一养成核心；不评价用户情绪的好坏，不要求用户保持快乐，不做 PK。

实现状态（截至 2026-11-08，以 GitHub 实际状态为准）：

- **已实现（main，PR #4 已合并）**：P1 Web 骨架——原文日记输入与保存、九类手动心情选择与确认、localStorage 整体存档、保存失败重试、损坏/未知版本恢复入口。代码中 `awardedXp` 恒为 0 占位，XP/装饰/隐藏结算与 AI 识别均未实现；角色视图为静态占位。
- **已合入（PR #5，本次修订执行期间合并）**：多页面 UI（写下今天 / 我的小人 / 回忆碎片）与独立小白人活动空间已在 main；角色仍为静态占位，无自主行为。
- **未实现（V2 规划）**：隐藏性格、习惯、自主行为、即时共鸣、世界成长与 Jev 接入，按 [ROADMAP](ROADMAP.md) 推进（U1 已合入，剩余 G1 → C1–C5）。

详细养成规则与数值的唯一来源是 [COMPANION_SPEC](COMPANION_SPEC.md)，本文件只概述并引用，不复制数值表。情绪字段见 [AI_CONTRACT](AI_CONTRACT.md)，状态模型见 [ARCHITECTURE](ARCHITECTURE.md)。

## 1. 核心循环与四种机制

1. 在「写下今天」输入原文日记；用户输入本身就是日记，正文原样保存、无产品人为字数上限，仅用 `text.trim().length > 0` 判断非空白，保存的仍是未经 trim 的完整原文；不做 AI 生成、润色、总结、扩写或改写。
2. 手动选择或发起 Jev 识别获得建议，最终确认九种心情之一，明确点击保存；识别期间不改变存档。
3. 保存成功后：自动导航至「我的小人」，小白人作出与本次确认情绪对应的一次**即时共鸣**；确认的 label 产生**隐藏性格**贡献；记录回忆（世界成长痕迹为 C4 候选机制）。共鸣是一次性运行时反馈：保存失败不跳转不播放，刷新/重复渲染/普通路由切换不重复触发，不额外结算成长；兼容手选与 AI 确认，减少动态效果下静态反馈（详见 COMPANION_SPEC 第 3 节；自动跳转与播放在 C4 实现，C1/C2 保留已有保存流程）。
4. 小白人在独立活动空间**自主生活**：性格影响行为权重，长期自主活动形成**习惯**，习惯再影响行为。
5. 用户通过观察实际行为、角色资料的自然语言描述与习惯标签发现成长，与小白人留下共同回忆；刷新、重开保留全部正式成果。

| 机制 | 职责 | 边界 |
| --- | --- | --- |
| 情绪识别 | 判断用户当前心情，产出建议 | AI 只产建议，必须经用户确认；无操作权限 |
| 即时共鸣 | 对当前心情作短暂温和回应 | 不永久锁定情绪，不写性格 |
| 隐藏性格 | 长期情绪记录塑造行为倾向 | 确定性规则计分，用户不可见数值 |
| 自主生活 | 按性格、环境、状态选择日常行为并形成习惯 | 本地规则驱动，不调用模型 |

四种机制相互关联但职责不混淆，详见 COMPANION_SPEC 第 1 节。提交按钮防重复；同一 entryId 只能创建一条正式记录；取消识别、关闭草稿不产生任何贡献。手动路径和 AI 路径使用同一套人格成长规则，没有 AI 的用户也能完整体验。

默认界面语言为简体中文。日记存储与 AI 输入限制分离：模型无法处理全文时明确提示，保留完整草稿并允许手选保存；不静默截断或伪装成全文分析。Jev 失败、超时、未配置 Key 时同样可手选。localStorage 容量/权限属于实际存储限制，保存失败必须保留草稿及旧存档并提示未保存；只有写入成功才显示持久保存成功，刷新后恢复日记、心情和角色。正文编辑原样替换 text，保留创建信息、心情与全部历史，不改变性格贡献，不自动重识别；重新识别或手动纠正须用户主动发起并再次确认。日记浏览与编辑体验在 C5 完善。异常恢复见架构。

## 2. 页面责任

| 页面 | 路由 | 责任 |
| --- | --- | --- |
| 写下今天 | `/` | 原文日记输入、情绪确认、AI 建议与手选、保存与重试 |
| 我的小人 | `/companion` | 独立宽敞的自然活动空间、自主行为、互动、角色资料（自然语言性格描述 + 习惯标签） |
| 回忆碎片 | `/memories` | 日记完整原文、情绪与成长回忆、纠正历史 |

三页结构已随 PR #5 合入 main。日记、角色和全部回忆不挤在同一页面；导航共享同一份应用状态，未保存草稿跨路由保留。日记成功保存后自动从 `/` 跳转至 `/companion` 并播放一次即时共鸣（C4 实现）；保存失败停留原页、保留草稿、不播放共鸣。默认首页最终指向日记还是小白人世界属待确认事项（见 COMPANION_SPEC 第 10 节）。历史列表支持查看保留空格换行的完整正文。

## 3. 情绪共生与即时共鸣

保留九种心情：joy 开心、calm 安心、sadness 悲伤、anxiety 焦虑、anger 愤怒、tired 疲惫、mixed 复杂、neutral 平常、unknown 说不清；字段与校验见 AI_CONTRACT。V、A、D 均为 0–1：V 愉快程度，A 激动程度，D 主观控制感，不是情绪好坏评分。

字段分工（已确认，替代旧版「所有规则只按 VAD 判断」）：

- **label**：隐藏性格基础评分与即时共鸣变体选择的主要依据。
- **VAD / intensity**：即时共鸣的表情细节、动作强弱与部分环境表现。
- **confidence**：仅用于识别结果提醒和确认，不作性格奖励倍数。

用户成功确认保存后，自动跳转至「我的小人」，小白人作出与本次确认情绪对应的一次轻量反馈，九种情绪各有不同且温和的表现（开心轻快蹦跳、安心安静舒展、悲伤安静陪伴、焦虑短暂停顿后舒缓、愤怒轻微活动后放松、疲惫坐下休息、复杂观察周围、平常继续普通生活、说不清好奇歪头；表现示例候选，见 COMPANION_SPEC 第 3 节）。共鸣是一次性运行时反馈：消费一次即清除，页面刷新、重复渲染、普通路由切换不重复触发，保存失败不跳转不播放；不永久锁定角色情绪，结束回到自主生活，不额外结算性格或习惯；手动选择与 AI 确认共用同一路径；减少动态效果模式静态显示同一情绪。全身白色基底不随情绪改成其他肤色。跨页面触发与一次性消费见 COMPANION_SPEC 第 3.1 节，接口边界见 ARCHITECTURE 第 2 节；自动跳转与播放在 C4 实现。

消极情绪是陪伴反馈，不是处罚：不扣除已拥有物品、不清除成长记录、不造成惩罚性后果。角色动作由本地确定性规则决定，AI 不能直接选择动画、操控角色或修改存档。

## 4. 成长与回忆（新版主玩法）

新版主要玩法为**隐藏性格 + 生活习惯 + 世界成长**，详细规则、评分表与候选参数唯一来源见 COMPANION_SPEC：

- **隐藏性格**：三个独立内部维度（探索欲、静心度、亲近倾向）；只有确认且成功保存的 label 计分；用户不可见精确分数、不可加点、不可选培养路线，只见自然语言描述与习惯标签；重复提交/刷新不重复计分，正文编辑不改变贡献，纠正按替换方案修订、不叠加（COMPANION_SPEC 第 2 节）。
- **生活习惯**：由多次真实自主行为跨多个活动日形成；用户不能直选，一次行为不形成，同日重复不无限积累；习惯影响行为概率但不排除其他行为，不离线衰减；互动不能直接刷性格（COMPANION_SPEC 第 5 节）。
- **自主行为**：发呆、散步、休息、探索、玩耍五种；性格影响权重，每种行为保留最低机会，不永久锁定；同时只有一个主要行为，互动与共鸣优先；页面隐藏暂停，关闭网页不模拟离线生活、不产生虚构离线经历（COMPANION_SPEC 第 4 节）。
- **世界成长与共同回忆**：独立宽敞活动空间已确认；植物、简单家具、回忆纪念物与情绪种子为候选机制；所有情绪都留下成长与回忆痕迹；区域扩展、地图规模与解锁价格未确认，不擅自定死（COMPANION_SPEC 第 6–7 节）。

不变量：性格分数不是健康指标或心理诊断；悲伤、愤怒不得导致小白人讨厌用户、永久失能或负面人格；已拥有物品、回忆与成长历史不因负面情绪、离线或纠正删除；性格、习惯、回忆与存档保持一致的原子提交边界，保存失败不改变正式状态。临时体验模式可在会话内运行完整性格计算与即时共鸣，但结果只在内存中有效，不写入或覆盖正式存档，刷新/会话结束可能丢失并须向用户明确提示，不得描述为已持久化；普通模式仍须整体存档成功后才正式计分（ARCHITECTURE 第 6 节）。

## 5. 旧版机制（待废弃或待保留，非当前正式规则）

以下 rules-v1 数值**不再作为 V2 正式成长规则**。P1 代码未实现其结算（`awardedXp` 恒 0、无物品目录），相关状态字段保留历史兼容，不销毁数据；存档演进见 ARCHITECTURE 第 6 节。

| 旧规则 | 与新方向的冲突 | 处理候选 |
| --- | --- | --- |
| 每条首次保存 5 XP；V ≥ 0.65 额外 5 XP；每 dayKey 上限 20 | 与「不以 XP 为唯一养成核心」冲突；积极额外奖励变相鼓励伪装积极 | 方案 A（建议）：废弃 XP 结算，字段保留兼容；方案 B：保留为不展示的辅助陪伴进度，数值重定待确认；方案 C：转化为世界成长痕迹的定性表达，不引入可刷取货币。最终取舍待用户确认 |
| 成长阶段阈值 0 初遇 / 30 相伴 / 80 共生 | 依赖 XP 数值 | 随 XP 取舍废弃或重定义；stage 字段保留 |
| 经验 10/30/80 解锁 ribbon / scarf / star-pin | 依赖 XP；装饰成长与新版世界成长体系重叠 | 待确认是否改为世界成长纪念物；已拥有数据不删除（当前实际无拥有数据） |
| 消极（V ≤ 0.35 且 intensity ≥ 0.6）隐藏 celebration 装饰；积极（V ≥ 0.65）全量恢复 | 与「消极情绪是陪伴不是处罚、所有情绪留下成长痕迹」方向冲突 | 建议废弃情绪触发的隐藏/恢复；用户手动穿卸与无条件恢复能力可作保留候选。若保留隐藏机制，原约束继续适用：只改可见性，保留所有权、原槽位与来源回忆，随时可恢复，无须先变开心 |
| 按 V/A 阈值五档表情动作表 | 与九情绪共鸣及 label/VAD 分工冲突 | 由 label 共鸣变体 + VAD/intensity 强度调制替代（第 3 节） |

本文件不同时保留两套互相矛盾的「当前正式规则」：第 3–4 节与 COMPANION_SPEC 是 V2 唯一正式方向；本节仅为历史机制的处置候选。是否保留 XP 作为辅助进度由用户最终确认，本文不认定任何数值系统已获批准。

## 6. 纠正、编辑与回忆

- 保存前纠正：采用用户选择的类别和维度，只保存一次有效结果；保留经 Provider 校验转换的规范化 AI 建议供本地查看，不保存厂商原始响应，不作为状态操作。
- 保存后纠正：记录原建议、原有效结果、新有效结果和修订号；不重复结算、不删除历史、不改写用户文本。性格贡献按 COMPANION_SPEC 第 2.4 节替换修订：同 entryId 只有一份有效贡献，跨日期纠正沿用原冻结 dayKey，原子保存。
- 仅最新记录纠正更新当前情绪与视觉；旧记录纠正修订其性格贡献但不覆盖最新情绪。用户主动恢复（若装饰机制保留）不被纠正撤销。
- eventId 标识一次操作，重试复用；entryId 标识一条日记，首次保存只结算一次；正文编辑与情绪纠正共用递增 Entry.revision 与旧修订校验，新修订不获得第二次首次结算资格。
- 回忆经 entryId 关联日记，保存时间、事件类型、确认情绪、识别来源与修订摘要；Entry 是正文唯一正式存储位置，回忆不复制完整正文，普通回忆详情展示该 Entry 编辑后的最新正文。纠正历史与成长事件完整保留，普通负面情绪不删除任何历史。新增习惯/互动/世界成长回忆类型见 ARCHITECTURE 第 4 节；时间线与纪念物在 C4/C5 按候选机制落地。

## 7. 长期陪伴与范围

小白人在用户不操作时自主活动，欢迎用户回来，不指责离开。禁止饥饿、掉级、死亡、断签损失、离线衰减、长期不登录惩罚与虚构离线经历。

MVP 不做：PK、多人、社交交易、无限聊天、语音、3D、商城付费、医学诊断、AI Agent 框架、长期聊天模型或复杂决策框架。文本只在用户点击 AI 识别时发送到服务端模型；手动路径不发送。浏览器数据不自动跨设备同步，清除站点数据会丢失本地存档；保留原始存档导出与显式重置能力，正式导出/导入在 C5 完善。用户主动删除/重置是独立明确操作，不能作为情绪后果。

## 8. 已确认与待确认

已确认方向：情绪陪伴与养成结合；半自主生活型小白人；不由用户直接指定性格培养方向；确认心情产生隐藏性格变化；用户看不到评分机制和数值；独立宽敞活动页面；不做 PK；负面情绪不是惩罚；本次只修订文档。

待用户确认的设计参数集中列于 COMPANION_SPEC 第 10 节（评分表数值、边界与日上限、习惯阈值、旧 XP 取舍、地图区域扩展、旧记录追溯、默认首页等）。未决参数不阻塞文档修订；对应实现阶段启动前确认或取得候选值授权。

## 9. 最小演示线与验收

V2 演示主线：原文日记 → 确认心情（手选 / Jev 建议）→ 即时共鸣 + 隐藏性格积累 → 小白人自主活动与习惯形成 → 世界成长与共同回忆。C1–C4 完成即具备新版核心玩法演示能力，C5 完善交互与部署；各阶段最小验收见 ROADMAP。旧 XP 演示线不再作为验收目标。

人工验收关键路径（实现后）：一条积极、一条消极、一条说不清均被接纳并留下痕迹；重复提交/刷新不重复计分；纠正替换贡献不叠加；无 API 手选路径完整；消极情绪无任何惩罚性后果；关闭重开不产生虚构离线经历；每次成功保存自动跳转小人页并播放一次共鸣，刷新/路由切换不重复播放、保存失败不跳转；临时体验成长仅内存有效且明确提示。已有有效验收不重复执行。
