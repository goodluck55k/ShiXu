## 3. 四页公共导航一致性（1440×900 实测几何）

四页 `/`、`/diary`、`/memories`、`/wishes` 完全一致：

- 侧栏 `x=10, y=18, w=230, h=864`；品牌 `28,63,194×42`；格纹胶带 `84,9,83×25`。
- 四个导航按钮均 `194×58`，`y=185/254/323/392`，选中态沿用鼠尾草绿。
- 月度心情小记 `y=466 h=109`、手账进度卡 `y=591 h=118`、底部植物便签 `y=727 h=88`（枝叶底 `823`）。

- 三个既有页面回归截图见 `regress-*.png`，布局与功能入口无退化。

## 4. 验证结果

- `npm run typecheck`、`npm run lint`、`npm run build` 全部通过；`/wishes` 为静态预渲染路由。
- 所有截图会话控制台 error/warning/exception 均为 clean。
- 交互实测：面板标签切换、输入、提交开发中提示、文字保留；空状态（桌面/手机）真实无样例。
- 生产隔离实测：`next start` + `?preview=sample` 仍为空状态（`production-preview-isolated.png`）。
- 低动态：星光呼吸与茶杯蒸汽动画在 `prefers-reduced-motion` 下关闭；无 JS 动画循环。
- 未验证：真实愿望数据下的状态映射与持久化（第二轮）；跨设备/长期体验；键盘走查仅依赖既有焦点样式与语义 tab/表单结构，未做完整读屏走查。
