### 归属与目标

- 阶段：许愿屋独立开发包第三轮（正式功能）。
- 模块：新增愿望领域模块 `wishes`、愿望存储适配器、愿望应用层；复用 `src/components/wishes` 展示层。
- 一句话目标：真实创建、持久化、手动完成愿望；杯内纸团与空中星星严格对应真实愿望；完成写入成功后才播放纸团升起变星星。
- 与现有模块隔离：不读写 `Snapshot` v4、日记、情绪、五维性格、主导、离线生活、重逢、企鹅行为；不调用 AI。

### 数据模型

```ts
interface Wish {
  id: string;                 // 稳定唯一标识
  text: string;               // 用户原始文本，按纯文本渲染
  status: "pending" | "completed";
  createdAt: number;          // 应用层显式提供
  completedAt: number | null; // pending 必须为 null
}

interface WishCollection {
  schemaVersion: 1;           // 当前唯一受支持版本
  revision: number;           // 非负整数，成功写入后 +1
  wishes: Wish[];
}
```

- 规则：新愿望只能以 `pending` 创建；只有用户手动操作才能完成；完成后记录 `completedAt`；重复完成、未知 ID 都是无副作用 no-op；原始文本与 `createdAt` 不可在完成时改写。
- 校验：非空文本（仅 `trim()` 判断，不裁剪保存内容）、稳定非空 ID、唯一 ID、合法状态、有限时间戳、`completedAt` 与状态一致。
- 不新增产品字数上限；存储额度不足时明确失败并保留草稿，不静默截断原文。
- 不关联九类情绪、VAD、五维性格、企鹅行为或离线生活。

### 存储

- 独立键：`shixu.wishes.v1`；值内 `schemaVersion = 1`。
- 独立适配器；保存前校验、检查现有 `revision`，只有写入成功才返回新集合。现有存档 `shixu.snapshot.v1` 与迁移链不变。
- 浏览器支持 Web Locks 时，用 `shixu.wishes.lock` 串行化跨标签页的“读取-比较-写入”；不支持时退回修订号检查 + `storage` 事件，不宣称绝对原子事务。
- 失败：存储不可用、额度不足、写入异常、损坏 JSON、未来版本均返回明确状态；损坏/未来版本保留原始 `raw`，提供导出与显式确认后的重置，绝不静默覆盖。
- 读取损坏/未来版本时不自动重置，不把原始数据当作空集合继续保存。

### 应用层流程

1. 加载：`missing` → 空集合；`ready` → 真实集合；`corrupt` / `unsupported-version` / `unavailable` → 对应恢复状态。
2. 创建：校验 → 生成 ID 与 `createdAt` → 构造候选集合 → 保存 → 成功后才更新列表并清空已保存输入；失败保留草稿与旧列表。
3. 完成：确认愿望仍为 `pending` → 构造 `completedAt` → 保存 → 成功后更新列表，并发出一次性 `{ wishId, nonce }` 动画信号；失败不改变状态、不播放成功动画。
4. 跨标签页：`storage` 事件命中愿望键时暂停本页写入并提示重新加载；保存返回冲突时同样处理。
5. 开发样例：仅 `NODE_ENV === "development"` 且 `?preview=sample` 时使用内存样例；创建/完成只在内存演示，不调用存储适配器；生产构建忽略该参数。

### 展示层边界

- `WishJar` 接收真实 `pending` / `completed` 视图集合与一次性完成信号；每个可见纸团/星星对应真实愿望 ID。
- 槽位由愿望 ID 稳定推导（哈希偏好 + 冲突探测），颜色、尺寸、倾角同样由 ID 稳定推导；保留已确认的不规则揉纸造型。
- 视觉上限沿用纸团 8、星星 5（候选参数）；超出时仅限制杯内绘制，愿望板与计数仍展示真实总数，不合并、不伪造。
- 完成动画只在持久化成功后开始；动画不写存储、不重复完成。不可见纸团或星星达到上限时使用非冒名的临时星光/静态反馈。
- `prefers-reduced-motion: reduce` 时直接静态切换，不渲染升起动画。
- 愿望板新增手动完成按钮、完成时间、进行中状态与错误提示；长文本换行、列表滚动、键盘可达；不新增编辑、删除、撤销完成或完成感想。
