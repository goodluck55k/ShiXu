## 3. 与已确认概念图的对照

### 已高度还原

- 桌面左侧手账目录：品牌、`little moments`、植物分隔、三个书签式入口、本月心情小记、手账进度、底部手写便签。
- 中央浅木色双页手账：书脊、奶油纸页、纸页叠层、纸张横线、胶带固定便签、错落角度、日期/心情/摘要/来源。
- 右页完整日记：日期时间、真实来源、情绪标签、完整原文、编辑正文、纠正心情、右下角坐着看书的企鹅与茶杯/书本/软垫。
- 手机单页竖向手账：品牌与标题、正文优先、相邻回忆、月度统计、手写便签、页码进度、底部三入口与安全区。
- 奶油白、暖纸张、浅木色、鼠尾草绿、暖棕文字的既有风格。

### 存在偏差及原因

| 偏差 | 原因 | 是否影响验收 |
| --- | --- | --- |
| 月度统计为真实 Top 3 情绪 + “其他”聚合，而不是固定的“开心/安心/平静/其他”四格 | 概念图数字是示例；仓库只允许九类既有情绪，不能创造“平静”等新分类 | 预计不影响；请用户确认统计口径与四格展示 |
| 纸张纹理、撕边、植物、胶带为 CSS/SVG 近似实现 | 概念图为手绘概念图，不是可切图的生产资源；禁止直接使用整图背景 | 需用户确认质感与细节程度 |
| 企鹅看书为已验收坐姿 SVG + CSS 书本/软垫组合 | 不得替换或重绘已验收母版 | 需用户确认装饰比例与位置 |
| 翻页为轻量淡入/位移，不是 3D 翻书 | 未批准具体物理翻书引擎；按低动态可降级实现 | 动效参数待验收 |
| 手机页面高于 844px 视口，需要滚动查看统计与底部翻页 | 真实正文、编辑/纠正、统计和装饰同时保留；未裁切功能 | 需用户确认是否接受滚动节奏 |
| 左侧索引最多 3 张便签 | 控制渲染量与视觉密度；全部记录可翻页到达 | 预计不影响 |
| 概念图中的头像、粉彩四格和手写情绪结论未直接照搬 | 避免暗示账号或伪造用户情绪结论 | 预计不影响 |
| 整页截图中固定底栏停在视口中部 | Playwright `fullPage` 截图对 `position: fixed` 的正常表现，不是页面布局错位；首屏与滚动到底部截图不受影响 | 不影响 |

## 4. 已验证结果摘要

- 8 条真实候选记录：页码 1/8 → 2/8 → 3/8 → 2/8，记录与右页全文正确同步。
- 首页上一页禁用、末页下一页禁用；单条记录 1/1 双向禁用；零记录显示真实空态。
- 未保存正文修改时翻页被阻止并显示提示，不静默丢失草稿。
- 正文编辑成功；保存失败时编辑框保留草稿并显示真实错误。
- 情绪纠正后正文保持不变，来源变为 `corrected`。
- 键盘 Enter/Space 可激活翻页按钮；`prefers-reduced-motion` 下翻页动画为 `none`。
- 1440/1920/390/375/360 宽度均无横向溢出；390×844 底栏安全区内翻页控件完整可达。
- 长正文 1734 字完整保存，右页滚动高度 3945px、可视高度 610px，可正常滚动阅读。
- 控制台仅有一条既有的静态资源 404（疑似默认 favicon），不影响回忆页功能。

正式视觉与动效参数仍需用户确认。
