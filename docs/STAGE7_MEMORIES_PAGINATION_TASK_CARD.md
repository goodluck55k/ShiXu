# 任务卡：阶段七补充开发包 · 回忆手账翻页（分支 `feature/memories-pagination`）

> 状态：**代码已完成，待用户视觉与功能验收。** 视觉基线为用户已确认的 [回忆手账正式视觉验收基线](STAGE7_MEMORIES_SCRAPBOOK_APPROVED.md)；候选分页规则（每条日记一页）待用户确认，不写成永久业务规则。

## 归属与目标

- 阶段：阶段七后续补充开发包（见 [ROADMAP](ROADMAP.md) §1.1 与“阶段七后续补充开发包：回忆手帐翻页”）
- 模块：`diary` 只读历史展示与既有编辑/纠正入口；`character` 仅复用已验收企鹅 SVG 作静态装饰
- 一句话目标：`/memories` 以真实日记驱动手账翻页阅读；桌面双页手账、手机单页手账均接近已确认概念图，同时保留正文编辑、情绪纠正与存档边界。
- 对应 Issue / PR：PR #40（`feature/memories-pagination` → `main`）

## 输入与输出

- 输入：`Snapshot.entries`（只读）、`useApp().editEntryText`、`EntryEmotionCorrection`、`EMOTION_NAMES`、`formatDateTime`、用户翻页/选页/编辑/纠正操作。
- 输出：`/memories` 只读分页视图、当前页详情、月度真实情绪聚合、编辑与纠正入口；不产生新领域事件、不新增持久状态。
- 状态所有权：仅拥有阅读页码、选中记录、编辑草稿与临时提示等运行时展示状态；不拥有日记正文、情绪、纠正台账、性格、行为或存档状态。

## 公共契约

- 新增契约：无。分页与统计为展示层派生，不写入 `Snapshot`。
- 修改契约：无；`Entry`、`Snapshot`、`schemaVersion` 4 保持不变。
- 消费的既有契约：`Entry`、`EmotionReading`、`EmotionSource`、`EMOTION_NAMES`、`useApp()`、`editEntryText`、`EntryEmotionCorrection`、`formatDateTime`。
- 禁止跨越：不得直接修改 `Snapshot`、不得调用评分/主导/行为/离线/重逢函数、不得引入新的日记或情绪规则；展示组件只读公开状态。

## 配置与版本

- 配置文件：无新增业务配置；分页为展示层候选规则。
- 规则版本：不改变 `rules-v1`、`personality-v2`、`behavior-v2`、`offline-life-v1`、`reunion-v1`。
- 可调参数：
  - 每条日记对应一个阅读页码（本轮候选规则，待用户验收）；
  - 时间倒序，`createdAt` 相同时以 `id` 字典序作为稳定次序；
  - 桌面左页展示当前及相邻少量便签；手机展示当前详情与少量辅助便签；
  - 侧栏/页内统计展示本月真实 Top 3 情绪 + 其他聚合；
  - 翻页动效时长、旋转角度、纸张纹理与断点均为待视觉验收参数。

## 依赖与边界

- 前置依赖：`main` 已合入 PR #38 的正式页面壳、`/memories` 路由、`DiaryHistory`、`EntryEmotionCorrection` 与移动端底栏安全区修复；PR #39 的翻页功能要求文档已合入。
- 明确不做：
  - 许愿屋、阶段八、饰品/家具/商店/货币、图片上传、默认图片图库、AI 新功能；
  - 修改五维评分、主导判定、九类情绪、日记保存结算、27 个行为 ID、离线生活、重逢、AI 契约或存档版本；
  - 将概念图作为整页不可交互背景；复制第三方美术素材；改写或摘要用户正文；
  - 把跨刷新记忆阅读位置写成已确认规则（本轮不持久化阅读位置）。
- 占位与真实：月统计、页码、便签与详情必须来自真实存档；装饰为原创 CSS/SVG 静态元素；企鹅仅复用已验收 SVG 母版，不新增动作或行为。

## 最小验收

- [ ] 零条日记显示真实空态，不出现示例日记或虚假页码。
- [ ] 一条日记显示第 1/1 页，上一页/下一页禁用。
- [ ] 多条日记按时间倒序翻页，页码与当前记录正确同步；首页上一页禁用、末页下一页禁用。
- [ ] 任意历史记录均可通过上一页/下一页或便签到达；同时间记录排序稳定。
- [ ] 桌面左页便签与右页全文联动；手机单页显示当前全文与少量辅助便签。
- [ ] 长篇正文完整可读、可滚动，不被裁切或遮挡操作按钮。
- [ ] 正文编辑沿用版本冲突校验，失败保留编辑内容；存在未保存修改时翻页被阻止并提示，不静默丢失。
- [ ] 情绪纠正沿用 `CORRECT_EMOTION`，不改变原文、不重复计分；纠正后来源与统计正确更新。
- [ ] 月度统计仅由真实已保存记录按九类情绪聚合，使用既有中文名，不新增情绪类别或伪造数字。
- [ ] 翻页按钮可聚焦、可用键盘激活；低动态模式下以静态切换代替复杂翻页动画。
- [ ] 360/375/390px 宽度无横向溢出；固定底栏、翻页与编辑/纠正按钮不被安全区遮挡。
- 验证方式：相关纯函数测试 + 一次 typecheck/lint/build + 真实浏览器桌面/手机冒烟与截图；不要求覆盖率。
- 未验证项：跨浏览器、实体设备、非零安全区、屏幕阅读器全量体验；视觉与动效参数待用户验收。

## 存档与迁移

- schema 变化：无（保持 `schemaVersion` 4）。
- 迁移策略：不涉及；不新增持久字段。
- 失败处理：编辑保存失败保留草稿与编辑态；存档异常沿用现有恢复提示；翻页本身不写存档。

## 风险与待确认

- 每页一条日记、左页便签数量、页码语义、是否记忆上次阅读位置与翻页动效均待用户视觉验收；不得把候选值写成不可调整的产品规则。
- 概念图中的日期、正文、情绪数量、`1/8`、统计四格与手写结论均为视觉示例；实际实现必须使用真实存档并遵循既有九类情绪字典。
- 桌面双页在窄平板可能偏紧；本轮按 700px 断点切换单页手账，平板比例与精确断点待验收。
- 装饰企鹅仅使用已验收 SVG 坐着姿态，不修改母版，不增加行为或交互。
