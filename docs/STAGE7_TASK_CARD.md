# 任务卡：阶段七 企鹅形象、表情动作、保存反馈与正式 UI

> 状态：**任务卡基线，部分开发包已合入**。角色与功能目标、页面路由、绘本空间、保存反馈条件与连续低落特殊行为规则已确认；正面母版（PR #27）与九种组合表情（PR #28）已合入并接入临时场景。侧面/背面与基础动作（PR #30）、特殊动作视觉（PR #31）已合入；生活空间与正式 UI 尚未开发；表情映射与动作参数仍待验收。详细背景见 [STAGE7_DESIGN](STAGE7_DESIGN.md)。

### 归属与目标

- 阶段：阶段七 企鹅形象、表情动作、保存反馈与正式 UI
- 模块：`character`（角色展示、表情、动作、生活空间与正式页面表现）；只读消费 `personality`、`behavior`、`offlineLife`、`reunion` 的既有快照/视图。
- 一句话目标：用户记录并保存情绪后，一只原创企鹅在自己的生活空间里自然地看向用户、给出符合本次情绪与长期性格的短暂反馈，然后继续自主生活。
- 对应 Issue / PR：正面母版 PR #27、九种组合表情 PR #28 已合入；其余开发包开工时填写。

### 开发包拆分与依赖顺序

阶段七不要求一次性完成，按以下顺序拆分独立分支与验收：

1. 企鹅正面母版（PR #27 已合入）
2. 九种组合表情（PR #28 已合入并接入临时场景）
3. 企鹅侧面、背面与基础动作（PR #30 已合入）
4. 抽烟、喝酒特殊动作及临时道具（PR #31 已合入，视觉已获用户确认）
5. 已确认特殊行为规则的正式接入（本分支实现，正式触发待用户验收；详见 [独立任务卡](STAGE7_SPECIAL_INTEGRATION_TASK_CARD.md)）
6. 小屋、自主生活与正式 UI 整合（未开发）

特殊行为开发包与正面母版、九种表情分开验收；规则已确认不等于功能已实现或可立即启用。

### 输入与输出

- 输入：`CharacterView` / `BehaviorDecision`、只读主导性格快照与描述、当前确认情绪、`lastConfirmedSave` 一次性上下文、离线事件与重逢问候（既有展示门控）、应用层显式时间/种子/`dayKey`。
- 输出：企鹅 SVG 与组合表情、基础动作表现、生活空间与正式页面；保存成功后的短暂反馈序列；不产生新的正式存档状态。
- 状态所有权：仅运行时展示状态（当前表情、动作、反馈阶段、暂停/低动态）；不拥有性格、行为选择、日记、离线、重逢或存档状态。
- 不拥有：五维分数、主导判定、行为权重/种子、保存结算、离线窗口、重逢触发。

### 公共契约

- 新增契约：原则上无。若表情/动作目录或生活空间需要新的稳定 ID，先作为配置与视图扩展评审；不得直接新增存档字段。
- 修改契约：可能扩展 `CharacterView` 的受控字段（例如表情/动作 ID 的取值）或新增只读视图类型；任何修改必须先更新 [ARCHITECTURE](ARCHITECTURE.md) 与调用方。`CharacterView` 的只读语义不变。
- 消费的既有契约：`CharacterView`、`BehaviorDecision`、`BehaviorRuleConfig`、`PersonalitySnapshot`、`dominantDescription`、`EmotionReading`、`ConfirmedSaveContext`、`OfflineLifeEvent`、重逢问候对象。
- 禁止跨越：渲染层不得读取完整 `Snapshot`、不得调用评分/主导/行为选择函数、不得重新抽样、不得修改 `applyGameEvent` 的结算结果；不得导入服务端 AI 模块。
- 特殊行为消费既有 `drink` / `smoke` 行为 ID 与 `special` 类别；不得新增存档字段或 V1 饰品字段。若动作/道具需要新的稳定视觉 ID 或扩展 `CharacterView`，必须先更新 [ARCHITECTURE](ARCHITECTURE.md) 与调用方。

### 配置与版本

- 配置文件：阶段七新增角色/表情/场景配置（目标位置开工时确定）；现有 `src/config/behavior.ts` 的动作时长与行为映射只读复用，不在渲染层复制权重。
- 规则版本：不改变 `personality-v2`、`behavior-v2`、`offline-life-v1`、`reunion-v1`。如新增角色配置版本，候选命名 `character-v1`，待用户确认。
- 可调参数：表情切换时长、保存反馈时长、转身/看向用户时长、动作幅度、场景尺寸与响应式断点等均待设计；不得把候选值写成最终规范。

### 依赖与边界

- 前置依赖：阶段二～六已合入 `main`（PR #18、#19、#20、#22、#23）；现有行为运行时、保存成功门控、离线与重逢展示边界稳定。
- 明确不做：
  - 服装、饰品、库存、槽位、解锁、穿戴；家具收集、物品商店、金币/货币奖励。
  - V2 饰品业务与解锁逻辑。
  - 修改五维评分、主导判定、行为池/权重/种子/防连续、离线生活或久别重逢规则。
  - 修改已确认的连续低落特殊行为规则（`sadness` 唯一标签、连续四个自然日、语义 B、`specialProbability=0.15`、停止条件）；或在特殊动作与触发逻辑验收前启用 `specialBehaviorEnabled`。
  - 把香烟、酒杯做成 V1 饰品、背包、库存或装扮内容；把抽烟/喝酒塞进九种面部表情或写成情绪改善手段。
  - AI 在运行时直接决定企鹅的自主行为、动作、表情或性格变化；渲染组件、行为引擎或存档流程调用 AI 参与决策或修改正式状态。
  - Electron、桌面宠物框架、后台常驻进程；把 React Kawaii 或 Penguin-Pet 作为运行时依赖。
  - 复制第三方角色造型、场景、UI 或受版权保护的美术素材。
  - 将未经确认的导航表现、场景比例或动画参数写成定稿。
- AI 辅助创作边界：开发阶段允许使用 AI 辅助创作原创企鹅形象、表情、SVG、生活空间与 UI 美术资源；最终资源须符合已确认的视觉方向、原创性与版权要求，并通过人工验收，不得直接照搬第三方受版权保护的角色或素材。AI 辅助创作不改变运行时权限：情绪识别仍只提供建议并经用户确认，五维评分、主导判定与行为选择仍由确定性规则和现有行为引擎完成。
- 占位与真实：正面母版与九种组合表情已合入；侧面/背面、基础动作和特殊动作已合入，正式场景尚未完成。不得把临时场景、占位或概念稿描述为已完成资源；概念稿不是仓库内可直接使用的完整 SVG。

### 最小验收

- [ ] 企鹅形象原创，符合已确认的圆润黑白造型、橘黄嘴/脚、无腮红与治愈系二维风格；不复制第三方角色。
- [ ] 身体与面部职责分离，眼睛、嘴巴等部位可独立组合；九类情绪表情可辨认，不同表情下角色形象一致。
- [ ] 五类主导性格的行为仍可辨认；待机、走路、转身、休息与互动反馈可在生活空间中表现。
- [ ] 页面隐藏暂停行为与动画；`prefers-reduced-motion` 降级仍生效；刷新后视图与正式状态一致。
- [ ] 保存成功并主动返回小屋后，符合有效条件的反馈至多触发一次：中断当前活动、转身或看向用户、按情绪与性格选择短暂表现、结束后恢复自主生活；保存失败不触发。
- [ ] 连续保存、互动打断、页面隐藏、组件卸载与重试不会造成重复反馈、计时器泄漏或状态错乱。
- [ ] 不出现服装、饰品、家具、商店或金币入口；不改存档 `schemaVersion` 与既有领域规则。
- [ ] `/` 小屋、`/diary` 日记、`/memories` 回忆独立可用；保留历史编辑/纠正与必要入口，旧 `/companion` 兼容为建议；空态、错误态、保存中/失败、离线恢复与窄屏可用。
- [ ] 日记无人为字数上限，AI 超限不阻碍手选保存完整原文；保存失败保留草稿。
- [ ] 保存后不强制跳转，主动返回小屋时仅有效的一次性反馈展示；只有已确认并正式保存的 `joy` 可在该反馈中出现短暂爱心，其他八类、开朗主导、普通互动及未保存的 AI 建议均无爱心。
- [ ] 保留 27 个行为 ID 与确定性选择；固定绘本小屋支持有限区域移动，重逢门控与反馈不叠加。
- [ ] 特殊行为开发包：`smoke` / `drink` 姿态、临时道具与短暂效果符合 STAGE7_DESIGN §A9；维持原创黑白企鹅、无腮红、不改变正面母版；道具不进入 V1 饰品/背包/装扮，不塞入九种表情。
- [ ] 特殊行为接入按 COMPANION_SPEC §3.5：`sadness` 唯一标签、连续四个自然日、第四天当天保存后具备资格（语义 B）、0.15 确定性抽样、`drink`/`smoke` 等权；未命中走正常行为；不加分、不发奖励；未完成验收前 `specialBehaviorEnabled=false`。
- 验证方式：人工页面冒烟 + 必要的规则/运行时回归 + 一次 typecheck/lint/build；不要求覆盖率。
- 未验证项：真实美术资源完成度、不同设备/浏览器的动画表现、用户最终视觉验收。

### 存档与迁移

- schema 变化：无（保持 `schemaVersion` 3）。
