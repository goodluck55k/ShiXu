## 第三轮：正式翻页功能（2026-11-16）

- 前置：第二轮视觉已由用户确认，桌面与手机视觉冻结；不重新设计双页结构、目录、纸张、木边、企鹅阅读、胶带植物、配色与字体层级。
- 输入输出、模块归属、公共契约、规则版本与存档 Schema 均不变；复用既有 `Entry`、`editEntryText` 与 `EntryEmotionCorrection`，不修改五维评分、企鹅行为、AI 与其他页面。
- 分页规则：按 `createdAt` 倒序，每页一条真实日记，最新一条为第 1 页；桌面左页展示当前及相邻便签、右页展示当前全文；手机单页翻阅；页码、总页数与翻阅进度全部由真实 `entries` 计算。
- 翻页：桌面采用两段式纸张轻翻（旧页离场、换页、新页进入）与页面光影；手机采用更轻量的位移淡入；动画期间锁定翻页入口；`prefers-reduced-motion` 下直接切换、无动画。
- 手机入口：书本顶部与书本下方均提供真实翻页控件；实测 390×844、375×667 无横向溢出，底部控件与固定导航至少间隔 48px。
- 草稿保护：编辑中正文有未保存修改时，阻止翻页与便签切换，并提示先保存或取消；保存失败提示与编辑内容保留不变。
- 最小验收：typecheck、lint、build；0、1、9 条真实记录；首尾页禁用；真实前后翻页；2160 字长文滚动；编辑保存；情绪纠正往返替换；低动态；360/375/390 宽度；刷新与新增记录后的页码。
- 状态：视觉已通过用户验收；真实翻页功能已提交，待最终功能验收。PR #41 保持 Draft，未合并，不进入许愿屋或阶段八。

## 第四轮：PR #41 三项 UI 专项整改（2026-11-16）

- 用户明确指出的三项 P1：三页左侧目录不统一、正文横线穿字/错位、现有翻页仍像卡片切换。本轮只做 UI、CSS 与展示层交互整改。
- 公共侧栏：新增 `src/components/AppSidebar.tsx` 作为唯一侧栏实现，`AppShell` 三页统一挂载。品牌区（绿色格纹胶带、四叶草、拾绪 ShiXu、little moments、「把日子轻轻收好」）、三个纸质导航入口、本月心情小记、手账进度与底部植物/手写文案全部共用；`APP_NAV` 为唯一路由定义。
- 统计：月度分类与数量只从真实 `entries` 聚合；手账进度显示真实总数。回忆页显示真实页码与翻阅进度，其余页面只显示总数与「到回忆碎片慢慢翻阅」引导，不伪造页码。三个页面统计卡、进度卡与底部装饰的几何位置一致，仅导航选中态和真实进度内容不同。
- 清理：移除 `.home-shell .sidebar`、`.memories-shell .sidebar` 的独立尺寸/外观覆盖与 `.scrap-sidebar-extra` 固定悬浮统计层；回忆页不再重复渲染侧栏统计。
- 小屋：侧栏右侧场景仍全屏铺满，不修改企鹅尺寸、行为、场景资源或镜头跟随；移动端继续使用统一底部三入口导航与安全区。
- 正文横线：删除 `.memory-full-text` 的 `repeating-linear-gradient` 背景横线，改用 `text-decoration-line: underline`、`text-underline-position: under`、`text-underline-offset` 与 `text-decoration-skip-ink: none`，让下划线跟随每个真实行盒；保留暖纸色、撕边、纸纹与长文滚动，不修改用户正文。
- 真实翻书：用独立动画层渲染纸页正反面（`perspective`、`rotateY`、`preserve-3d`、`backface-visibility`、书脊轴、动态阴影、纸页厚度边与卷曲高光）。下一页 0°→-180°，上一页 -180°→0°（手机 -95°→0°），正文层在下一页 90°、上一页落页前切换；动画结束卸载纸页。低动态直接切换。
- 交互保持：首末页禁用、连续快速点击只前进一页、草稿未保存禁止翻页、保存失败保留草稿、页面隐藏/卸载安全收尾、键盘 Enter 可用、翻页后焦点保留、动画期间正文层 `inert` 禁止编辑/纠正。
- 不改范围：五维评分、主导判定、九类情绪、保存结算、情绪纠正领域逻辑、企鹅行为与 27 个行为 ID、离线生活/久别重逢、AI 适配器、存档 Schema、小屋美术、手账主题配色；不新增许愿屋/图片上传/饰品/商店。
- 最小验收：typecheck、lint、build；三页侧栏几何对比；2058 字中英混排/手动换行长文在 100%、125%、150% 与 390/375 宽度下的下划线；桌面与手机前后翻页 MP4、0/50/100% 关键帧；草稿保护、快速点击、低动态、隐藏恢复、键盘与真实鼠标点击测试。
